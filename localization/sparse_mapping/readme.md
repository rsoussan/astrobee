\page sparsemapping Sparse Mapping

# Package Overview
The sparse mapping package provides several tools for the generation of a sparse map described below.
See \ref map_creation for more information on the map creation pipeline.

## Usage Instructions
For each tool and script, run `rosrun sparse_mapping tool_or_script_name -h` for further details and 
usage instructions.

# Tools
## `remove_low_movement_images`
Removes successive images with little relative movement.

# Scripts
## `make_surf_map`
Creates a surf map for a provided bagfile.
